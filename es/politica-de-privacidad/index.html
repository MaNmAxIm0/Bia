Política de Privacidad

1. Introducción

Esta Política de Privacidad explica cómo Beatriz Rodrigues recopila, utiliza y protege tu información personal cuando utilizas este sitio web.

2. Información que Recopilamos

  • Nombre
  • Dirección de correo electrónico
  • Número de teléfono
  • Datos de uso (IP, navegador, páginas visitadas, etc.)

3. Uso de Cookies

Utilizamos cookies y tecnologías similares para mejorar tu experiencia, analizar el tráfico y personalizar el contenido.

  • Cookies necesarias: esenciales para el funcionamiento del sitio.
  • Cookies de análisis: nos ayudan a entender cómo se usa el sitio.
  • Cookies de marketing: pueden ser usadas por socios para mostrar anuncios relevantes.

4. Cómo Utilizamos tu Información

  • Para proporcionar y mantener el servicio
  • Para notificarte sobre cambios
  • Para permitir funciones interactivas
  • Para atención al cliente
  • Para análisis y mejora del servicio
  • Para monitorear el uso
  • Para detectar y prevenir problemas técnicos

5. Compartir Datos

No vendemos ni transferimos tu información personal a terceros, salvo lo descrito en esta política.

6. Seguridad de los Datos

Tomamos medidas razonables para proteger tus datos, pero ningún método es 100% seguro.

7. Tus Derechos

  • Acceso, rectificación y eliminación de tus datos
  • Restricción y portabilidad

8. Retención de Datos

Conservamos tus datos solo el tiempo necesario para los fines descritos.

9. Transferencias Internacionales

Tus datos pueden ser transferidos y almacenados fuera de tu país.

10. Cambios a Esta Política

Podemos actualizar esta política y publicaremos los cambios en esta página.

11. Contacto

Si tienes preguntas sobre esta política, contáctanos.
